# Overnight spikes (2026-11-11)

Everything below is on `claude/overnight-all` (one build to play with) and on its own branch / draft PR.
Build: Debug with `PRODUCT_BUNDLE_IDENTIFIER=com.orriginal.browsa.overnight BROWSA_APP_NAME="Browsa Overnight"`,
so its data is separate from Browsa and Browsa Dev.

| Spike | PR | Try it |
|---|---|---|
| Boosts | #58 | On any site: ⌘K › Open Boost. Pick a font, slide the colour, Zap an element, add CSS. |
| !bangs + calculator | #59 | ⌘T: `!yt lo-fi`, `swift actors !gh`, `!w`; `12*7+3`, `15% of 80`, `5 km in mi` (Return copies). |

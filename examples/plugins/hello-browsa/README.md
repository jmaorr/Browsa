# Hello Browsa

The smallest useful Browsa plugin. Load it from the Library: Add Unpacked Folder…, then pick this folder.

You get:
- a **Hello** panel in the right panel (⌘K › Open Hello),
- a **sidebar card** with a clock,
- ⌘K › **Reading Time for This Page** and **Say Hi from Hello Browsa**, plus **Open a Random Wikipedia Article**,
  which the plugin registers while it runs.

Turn on Settings › Inspect Element to get the **Plugin Console** (⌘K › Open Plugin Console), which shows every
message and has Reload Extensions. See `docs/plugins.md` for the API.
